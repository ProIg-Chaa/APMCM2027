# B题第二问：十炉过程曲线、累计排放与关系分析

## 计算口径

- 输入为上一阶段十炉重构结果，不读取或改写原始 XLSB 数据。
- 时间网格为 0.5 s。CO₂、CO 累计排放采用复合梯形积分：`E(t)=∫q(t)dt`。
- CO₂ 与 CO 的固定有效延迟分别采用 34 s 和 32 s，来自十炉留一炉验证后选出的稳健基线。
- 每炉曲线表含氧枪流量、累积耗氧量、CO₂ 流量、CO 流量、CO₂ 累计排放和 CO 累计排放。氧枪流量为相邻累积耗氧量之差除以 0.5 s，首个时刻无前一区间，因此留空。

## 主要结果

- 十炉 CO₂ 总排放范围为 4829.9–10989.5 m³，均值为 9303.1 m³。
- 十炉 CO 总排放范围为 10996.4–24869.6 m³，均值为 19768.4 m³。
- 单炉内累积耗氧量与累计 CO₂ 排放的 R² 为 0.983–0.997，与累计 CO 排放的 R² 为 0.917–0.969。
- 延迟对齐后，氧枪流量与 CO₂ 流量的 Pearson 相关系数为 -0.277–0.785，与 CO 流量为 0.138–0.700，说明瞬时响应在炉次间有明显差异。
- 跨炉最终耗氧量对 CO₂ 总排放的 R² 为 0.060，对 CO 总排放的 R² 为 0.182，均不足以支持稳定的跨炉线性关系。

## 解释边界

单炉“累积量—累积量”的高 R² 同时受到共同时间趋势影响，不能单独作为因果证据。论文中应把它表述为过程内同步累积特征，并结合延迟对齐后的瞬时流量关系及跨炉总量检验共同判断。当前证据支持固定延迟作为十炉稳健基线，不支持建立统一的动态延迟函数。

## 输出文件

- `per_heat_curves/`：十炉六条过程信号的可复用数据。
- `per_heat_relationships.csv`：逐炉瞬时、延迟对齐及累计关系指标。
- `per_heat_totals.csv`：逐炉最终耗氧量与 CO₂、CO 总排放。
- `cross_heat_relationships.csv`：跨炉总量相关与线性拟合。
- `figures/`：十张单炉六联图和两张十炉汇总图，均含 PNG 与 PDF。
- `experiment.json`：采样、延迟、积分方法和解释限制。
