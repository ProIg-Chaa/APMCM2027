# APMCM2027

2027 年亚太杯数学建模竞赛三人协作仓库。

| 目录 | 内容 |
| --- | --- |
| `problem/` | 赛题原文、附件和参考资料 |
| `data/` | 原始数据及处理后的数据 |
| `src/` | 数据处理、建模、求解和绘图代码 |
| `results/` | 实验结果、图表与关键输出 |
| `paper/` | 论文稿件和最终提交版 |

## 协作

- 三人可按建模、编程和论文写作分工，具体安排由团队确认。
- 每次开始前同步 `main`，从 `main` 创建自己的工作分支，完成后通过 Pull Request 合并。
- 保留原始数据，处理后的数据另存。把运行命令和关键参数随相关代码记录，方便队友复现结果。
