# 十炉信号重建、时延估计与模型比较

本实验将第一炉确定的流程原样应用到附件 1–10。原始 XLSB 文件仅用于读取，所有派生结果写入独立目录。

## 固定流程

- 累积耗氧量使用名义节点间距 10 s 的单调分段线性拟合，再按相邻 0.5 s 区间斜率计算氧枪流量。
- CO₂、CO 使用名义节点间距 5 s 的 Huber 稳健分段线性拟合。
- 时延估计使用 120 s 窗口和 30 s 步长，在 0–60 s 范围搜索局部去趋势相关系数最大值。
- 可靠窗口要求相关系数不低于 0.45、相关峰高于该窗口中位数至少 0.08、氧枪流量标准差不低于 0.10 m³/s，而且峰值不位于搜索边界。
- 候选时延模型包括固定时延、单调线性、反比例和单调回归。
- 采用逐炉留一验证。模型选择使用每个测试炉 RMSE 的等权平均，避免可靠窗口较多的炉次主导结果，同时保留按窗口汇总的 RMSE 和 MAE。

## 数据覆盖

十炉共得到 57 个可靠 CO₂ 窗口和 67 个可靠 CO 窗口，每种气体均覆盖全部十炉。第五炉时间最短，CO₂ 仅有 1 个可靠窗口。第一炉 CO 也仅有 1 个可靠窗口。这些窗口仍参与测试，但每炉等权指标限制了窗口数量不均衡的影响。

## 时延—流量关系

- CO₂ 的 pooled Spearman 相关为 -0.034，p=0.800，没有显示稳定的单调关系。
- CO 的 pooled Spearman 相关为 -0.424，p=0.00035，整体方向符合流量增大、时延缩短的物理预期。
- 逐炉内部的关系方向并不完全一致，说明炉次阶段、反应状态或未观测因素会显著影响局部相关峰。

## 跨炉模型结果

CO₂ 的每炉等权平均 RMSE 分别为：固定时延 16.49 s、单调线性 18.35 s、反比例 17.63 s、单调回归 17.76 s。固定时延最稳。

CO 的每炉等权平均 RMSE 分别为：固定时延 15.02 s、单调线性 15.80 s、反比例 15.51 s、单调回归 15.65 s。固定时延仍最稳。按窗口加权时，CO 的单调回归 RMSE 为 15.52 s，低于固定时延的 16.55 s，但这一优势没有在每炉等权指标中保持。

在全部可靠窗口上重新拟合后，固定模型的代表值为 CO₂ 34 s、CO 32 s。它们是当前十炉数据下的跨炉基线，不等同于纯管道输送时间，也不能替代每炉的局部诊断。

因此，现阶段不支持把“流量决定时延”作为唯一关系。后续光谱预测可把 34 s 和 32 s 作为稳健基线，并把局部动态时延或流量特征作为扩展实验。若需要继续提高动态时延模型，应加入吹炼阶段、烟气水平或光谱状态等变量，并使用独立的时延可靠性检验。

## 主要输出

- `heat_summary.csv`：每炉长度、可靠窗口数及固定时延候选。
- `reliable_windows.csv`：十炉所有通过筛选的局部时延窗口。
- `pooled_relationship_summary.csv`：流量—时延的 pooled 相关统计。
- `model_comparison.csv`：四种模型的逐炉留一汇总指标。
- `per_heat_model_errors.csv`：每个测试炉、每种模型的 RMSE 和 MAE。
- `leave_one_heat_out_predictions.csv`：逐窗口测试预测。
- `fitted_model_curves.csv`：使用全部可靠窗口拟合的候选曲线。
- `all_window_delay_estimates.csv` 与 `all_window_correlation_curves.csv`：完整时延诊断。
- `per_heat/`：每炉的重建信号、氧枪流量及窗口结果。
- `figure_1_heat_summary.pdf/png`：各炉可靠窗口与固定时延候选。
- `figure_2_delay_models.pdf/png`：可靠窗口、模型曲线和逐炉留一误差。

## 复现

在仓库根目录运行：

```powershell
python src/question2/ten_heat_reconstruction_delay.py --output-dir results/question2/ten_heat_reconstruction_delay_rerun
```

程序拒绝覆盖已有输出目录。输入接口保持第一列为采样序号、末三列依次为累积耗氧量、CO₂ 和 CO。
